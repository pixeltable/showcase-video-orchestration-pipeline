# Evidence workspace design

Inherit the existing showcase's near-white reading surface, dark text, blue actions, system
type, restrained rules, and dark-mode counterpart. This is an Operate surface: previews and
their current eligibility occupy the left column; saved request evidence and scoped refresh
occupy the right. At small widths, source and rule come before stored requests.

Use real generated media rather than decorative imagery. Keep the rule, current frame
selection, and each stored result visible together. Mark a stale request in words as well as
color. Preparation and evaluation counts are a compact ledger, not headline metrics.
Primary controls have keyboard focus, loading and error states. There are no external
fonts, assets, uploads, marketing claims, or paid-call controls on this surface.
